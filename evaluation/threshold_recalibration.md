## Where the benign false positives fall

A single blended false positive rate hides the actual pattern. Broken down by endpoint, at a threshold of 0.80:

| Endpoint | Benign requests | Scoring ≥ 0.80 |
|---|---:|---:|
| /api/auth | 25 | 2 |
| /api/orders | 32 | 0 |
| /api/search | 64 | 0 |

If the false positives concentrate on `/api/auth/*`, the cause is not the threshold: it is the payload classifier scoring credential POST bodies, whose high entropy and special-character density resemble the attack payloads it was trained on. The behavioural attacks against those endpoints (brute force, credential stuffing) are detected by the rule stage, not the payload model, so the model has nothing to add there and a great deal to get wrong.
